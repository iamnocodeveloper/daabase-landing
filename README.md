# daabase-landing

Landing page pública del miniSaaS `daabase`. Desplegada en Netlify.

## Stack

- Next.js 15 + Tailwind CSS
- Despliegue: Netlify
- Dominio: https://daabase.click

## Primeros pasos

```bash
pnpm install
pnpm run dev
```

## Secciones

- Hero
- Demo
- Benefits
- Snippet (código de ejemplo)
- Waitlist form
- FAQ
- Footer con atribución Apache 2.0

## Atribución

Esta landing incluye atribución a InstantDB según la licencia Apache 2.0.
Ver `/atribucion`.
